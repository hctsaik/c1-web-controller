# C1 練習板

給 LiberLive C1 練習用的**非官方**網頁。畫面與操作刻意靠近官方 App，方便小朋友轉換：選曲譜、跟著和弦色塊彈唱、看哪個和弦墊該按。也可以用 Web Bluetooth 連接真的 C1，把按鍵與撥片顯示在畫面上。

這**不是** LiberLive 官方產品，沒有使用官方 SDK，也**不會讀取官方歌庫**。只能使用內建的公共領域示範曲，或你自己貼上的曲譜。協定整理自第三方專案 [orinayo-pico 的 `uni_bt_le.c`](https://github.com/Jus-Be/orinayo-pico/blob/master/bluepad32/bt/uni_bt_le.c)，屬於非官方解析，可能隨韌體改變而失效。

線上版本：https://hctsaik.github.io/c1-web-controller/

模擬預覽（不必接琴）：https://hctsaik.github.io/c1-web-controller/?mock=1

## 使用前請先看

1. 請先**完全關閉官方 LiberLive App**。C1 同時只能連一台裝置。
2. **不要**在手機的系統藍牙設定裡配對，請只用「設定 → 我的裝置」裡的「連線 C1」。
3. 請把這個分頁**保持在前景**。
4. iPhone / iPad 的 Safari **不支援** Web Bluetooth，請改用 Android 或電腦上的 Chrome。
5. 請只貼你有權使用的歌詞與和弦，不要匯入官方付費或受保護的曲庫。

## 給小朋友怎麼用

1. 打開網站（或加上 `?mock=1` 先練習畫面）。
2. 在「曲譜」選示範曲（小星星、兩隻老虎、歡樂頌），或按「自製曲譜」貼上例如：

   ```
   標題: 練習曲
   調: C
   速度: 80
   每格拍數: 2

   [C] 第一句 [G] 第一句
   [Am] 第二句 [F] 第二句
   ```

   自製曲譜會存在這個瀏覽器（localStorage），不會上傳。
3. 進入彈唱頁後，會看到像官方 App 那樣往前推進的彩色和弦色塊。下方七個指示燈對應 C1 由琴頭往琴身的預設和弦墊：C、Dm、Em、F、G、Am、Bm。亮起來的就是現在該按的鍵。
4. 按「開始彈唱」，跟著速度彈；連上真的 C1 時，按墊與撥片會自動算進分數。模擬模式可以點畫面上的和弦墊來練習。
5. 結束後會看到「實驗性」粗略得分：只要在該小節前後一點時間內按對和弦就算。這不是官方評分。
6. 「和弦指板」可即時看調、速度、撥片與七個墊的狀態。「設定」可連線、使用 MIDI，以及打開「除錯」。

## 用真實 C1 測試

1. 用 Android 的 Chrome 打開 https://hctsaik.github.io/c1-web-controller/
2. 關閉官方 LiberLive App，打開 C1 電源。
3. 到「設定 → 我的裝置」，點「連線 C1」，在系統視窗裡選名稱以 `Liber` 開頭的裝置（官方名稱是 LiberLive C1）。若清單是空的，再試「掃描全部裝置」。
4. 連上後，可在「除錯」區塊核對 GATT 清單：
   - 來源記載的服務是 `000000ff-0000-1000-8000-00805f9b34fb`
   - 特徵是 `0000ff03-0000-1000-8000-00805f9b34fb`
   - 若對不上，請用清單上的「訂閱通知」「設為寫入目標」手動選。
5. 回到「曲譜」選一首歌開始彈唱，或到「和弦指板」對照琴上的按鍵與撥片。
6. 「寫入和弦對應」會送出來源在連線後實際寫入的 26 位元組，**可能會改到琴上的和弦配置**，請大人決定要不要送。
7. 「實驗性」按鈕只送出原始碼裡出現過、但被註解掉的封包。來源沒寫的內容，請用手動十六進位寫入。
8. 若要對 MIDI：在「設定」啟用 MIDI，選指令後按「開始學習」，再按下琴鍵、踏板或送出 Program Change。對應表存在這個瀏覽器。

若官方 App 能連、這個網頁不能連，可能是官方 App 仍占著連線，或瀏覽器不支援 Web Bluetooth。

## 本機開發

```bash
python3 -m http.server 8080
# 另開終端
npm test
```

單元測試涵蓋通知解析、指令組裝與曲譜／計分，不需要實體裝置。Web Bluetooth 實際連線必須用真實的 C1 在 Chrome 裡驗證。

```bash
npm install --no-save playwright@1.56.1
npm run screenshots
```

會輸出 412×915 的手機畫面到 `screenshots/`。官方 App 的參考截圖只放在本機的 `ref/`，不會提交到公開倉庫。
